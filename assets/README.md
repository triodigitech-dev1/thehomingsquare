# Chess textbook assets

This directory contains reusable assets and research pointers for the supplied
manuscript. Files are grouped by their role in the book:

- `images/` — open-source reference images from Chessground.
- `opening-data/` — Lichess chess-opening names and PGN/FEN data, released under CC0.
- `research/` — source documentation for the Lichess game database and Syzygy tablebases.
- `licenses/` — licence texts for redistributed open-source files.
- `concepts/` — the manuscript-wide concept and source map.

The external research sources listed in `concepts/source-register.json` are not
copied into this repository when their terms prohibit redistribution. They are
provided as research links and must be cited or checked individually before
publication.

## Reuse rules

1. CC0 opening data may be reused, modified, and redistributed.
2. Chessground files are GPL-3.0; retain the licence and attribution if those
   files are used in a distributed product.
3. Lichess databases and puzzle exports should be downloaded from the official
   source and used according to the current terms shown there.
4. ChessBase, Chess.com, TWIC, books, and commercial course material are
   research sources only unless separate permission is obtained.
5. Historical photographs and artwork require file-level licence verification.
